# Tanay Agarwal — Portfolio

## About

A personal portfolio website built with pure HTML and CSS. Clean, responsive, and modern — designed to showcase my projects, skills, and journey as a Computer Science student.

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, Animations, Media Queries)

## Sections

- **Navigation** — Sticky navbar with CSS-only hamburger menu for mobile
- **Hero** — Introduction with profile image and CTA buttons
- **About** — Personal introduction with stat cards
- **Skills** — Categorized skill pills (Frontend, Tools, Currently Learning)
- **Projects** — Project cards with descriptions, tech tags, and links
- **Education** — Timeline layout
- **Contact** — Form + social info cards
- **Footer** — Social icons and copyright

## Features

- ✅ Fully responsive (Mobile, Tablet, Desktop)
- ✅ CSS-only hamburger menu (no JavaScript)
- ✅ CSS transitions and hover effects
- ✅ Keyframe animations (fade-in, float, gradient border)
- ✅ CSS Grid + Flexbox layouts
- ✅ CSS custom properties (design system)
- ✅ Semantic HTML
